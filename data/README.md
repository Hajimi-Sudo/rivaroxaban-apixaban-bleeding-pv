# Data guide

This repository contains only frozen aggregate, non-patient-level outputs.

- `aggregate/` contains the tables underlying the paper results and figures.
- `raw/` contains instructions for obtaining the official source releases.
- Raw spontaneous-report archives are intentionally excluded from Git.
- No individual case safety reports are published in this repository.

The aggregate outputs describe reporting patterns and must not be interpreted as incidence, prevalence, treatment risk, or causality.
